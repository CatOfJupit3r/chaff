# Support

Start with the [README](README.md), which covers install, updating and every screen, and the [project page](https://catofjupit3r.github.io/chaff/).

Search [existing issues](https://github.com/CatOfJupit3r/chaff/issues) before opening a new one. Use the bug form for something that behaves wrong and the feature form for a concrete idea.

A good report says which commit you built (`git rev-parse --short HEAD`), your OS, how you run Chaff (installed app or `pnpm run dev`), what you did, what you expected and what happened. A screenshot or a small demo repository helps a lot.

Chaff is a side project. There is no guaranteed response time.

Suspected vulnerabilities go through [SECURITY.md](SECURITY.md), not a public issue.
